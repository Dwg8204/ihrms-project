HUONG DAN HOC VA BAO CAO THEO MODULE (IHRMS)
Ngay cap nhat: 2026-05-07

====================================================
1) Kien truc tong the va cach doc du an
====================================================

Stack:
- Backend: Node.js + Express + MySQL (mysql2/promise)
- Frontend: React + Vite + Axios
- Upload file: multer + cloudinary

Quy uoc Backend:
- Route: dinh nghia endpoint HTTP
- Controller: validate input, dieu huong nghiep vu, tra response
- Model: thao tac SQL voi DB
- Middleware: upload, xu ly loi

Quy uoc Frontend:
- services/*.js: dong goi API call
- pages/*.jsx: xu ly state, form, action, goi service
- components/*: UI tai su dung

Data flow 1 request:
FE Page -> FE Service -> HTTP client (axios) -> API Route -> Controller -> Model -> MySQL

Dang response backend thuong gap:
- Thanh cong: { success: true, data, message?, pagination?, summary? }
- Loi: { success: false, message }

====================================================
2) Khung chuan de viet 1 module moi (API -> FE)
====================================================

Buoc 1. Database
- Tao migration SQL (them bang, index, FK, unique)
- Chay migration vao DB

Buoc 2. Model (backend/models)
- Viet ham CRUD + ham nghiep vu can thiet
- Tach ro query list (co filter/page), query detail, create/update/delete

Buoc 3. Controller (backend/controllers)
- Parse req.params, req.query, req.body
- Validate du lieu (format, range, business rule)
- Goi model
- Dung ma HTTP dung nghia: 200/201/400/404/409/500
- Day loi qua next(error) de middleware xu ly

Buoc 4. Route (backend/routes)
- Mapping endpoint -> controller
- Them middleware upload neu co file

Buoc 5. Register route vao server
- app.use('/api/<module>', moduleRoutes)

Buoc 6. FE Service (frontend/src/services)
- Tao cac ham get/create/update/delete
- Return res.data de Page dung thong nhat

Buoc 7. FE Page (frontend/src/pages)
- Quan ly state du lieu, loading, modal, form
- Goi service trong useEffect va event handler
- Hien thi toast thanh cong/that bai

Buoc 8. Test nghiep vu
- Test duong di thanh cong
- Test validation fail
- Test xung dot du lieu (duplicate, status transition sai)

====================================================
3) Module 1 - Recruitment (Ung vien + Nguon)
====================================================

Muc tieu:
- Quan ly ung vien, nguon tuyen dung, funnel/kanban trang thai

Backend APIs chinh:
- GET /api/candidates
- GET /api/candidates/:id
- POST /api/candidates (multipart/form-data, cv_file)
- PATCH /api/candidates/:id
- PATCH /api/candidates/:id/status
- DELETE /api/candidates/:id
- GET /api/candidates/kanban
- GET /api/candidates/funnel-summary
- GET/POST/PATCH/DELETE /api/recruitment-sources

Xu ly nghiep vu noi bat:
- Chuan hoa payload snake_case/camelCase
- Validate CCCD 12 so, phone VN, email, ngay sinh, chieu cao/can nang
- Validate source_id bat buoc va ton tai
- Khong cho update status bang endpoint update thuong (ep dung endpoint status rieng)
- Luc tao candidate: init ho so PRE_EXAM + tu dong sinh lich thu phi dang ky

Lien ket FE:
- recruitmentService.js goi candidates + recruitment-sources
- RecruitmentPage.jsx quan ly form tao/sua, filter, kanban, funnel

13) Auth va ket noi FE-BE
====================================================

Auth hien tai:

- Controller tra ve token random + user
- FE luu vao localStorage key: ihrms_admin_auth

HTTP client FE:
- frontend/src/services/http.js
- baseURL = VITE_API_BASE_URL hoac mac dinh '/api'

Route guard FE:
- App.jsx check auth de vao layout/chuyen ve /login

====================================================
14) Error handling, validation, va convention bao cao
====================================================

Backend:
- notFoundHandler: route khong ton tai -> 404
- errorHandler: loi chung -> statusCode + message
- Validation logic nam trong controller + utils/inputValidation.js

Frontend:
- Moi action API boc try/catch
- Dung getErrorMessage(err) + toast de thong bao

Convention nen dua vao slide:
- 400: input sai
- 404: khong tim thay
- 409: xung dot du lieu/nghiep vu
- 500: loi he thong

====================================================
15) Mau quy trinh trinh bay 1 use case (de bao cao)
====================================================

Use case mau: Tao ung vien moi
1. User nhap form tai RecruitmentPage, chon CV file.
2. recruitmentService.createCandidate(formData) goi POST /api/candidates.
3. candidateController validate CCCD, source, phone/email...
4. candidateModel insert vao bang candidates.
5. documentModel init bo document PRE_EXAM.
6. paymentScheduleModel generate phi su kien dang ky.
7. API tra ve candidate vua tao.
8. FE refresh list + thong bao thanh cong.

=> Day la luong "API -> nghiep vu -> DB -> FE render" chuan de thuyet trinh.
